# Verbo Academy Final

Create a high-end, premium B2B Learning Management System (LMS) for an English School named "Verbo Language Solutions". 




DESIGN SYSTEM & UI:

- Strictly minimalist, premium, and corporate aesthetic. 

- Monochromatic color palette (deep blacks, crisp whites, clean slate grays) with a very subtle accent color (like an elegant brand orange or blue) used exclusively for primary action buttons.

- Modern typography, generous whitespace, soft micro-shadows, and smooth rounded corners. Completely avoid generic or cluttered layouts.




USER ROLES & AUTHENTICATION:

- Implement a single custom Landing Page (Hero section introducing Verbo) with a secure "Sign In" button in the top right corner.

- Completely disable social logins (Google, FB, Apple). Users can only access via private email/username and password credentials manually generated by the Admin.

- Setup a multi-tenant role system with three distinct permissions: 

  1. Student

  2. Teacher

  3. Admin

- The system must detect the User Role upon login and securely redirect them to their respective dashboard, preventing cross-access to unauthorized URLs.




DATABASE RELATIONSHIPS (The Core Foundations):

1. Users Table: (id, name, email, role, current_level, attendance_percentage).

2. Assignments Table: Links specific Students to specific Teachers. Teachers should ONLY see their assigned students' sessions and data.

3. Sessions Table: (id, student_id, teacher_id, date_time, teams_link, status: scheduled/completed/absent/delayed, report_pdf_url, student_rating).

4. Courses Table: Hierarchical structure: Levels (e.g., A1, A2, B1) -> Units -> Pre-unit view (Video Player placeholder, PDF download button, "Start Activities" button).

5. Supplementary Material Table: (id, material_type: book/pdf/verb-list/video/image, upload_url, category).




CORE PAGES TO GENERATE:




1. STUDENT DASHBOARD:

- Clean top navigation bar: Dashboard, Live Sessions, Courses, Resources, Profile Icon.

- High-level metric cards: Level Progress (%) and Overall Attendance (%).

- "Current Course" card with a prominent "Continue" button leading to the current unit.

- "Upcoming Sessions" section: Displays scheduled classes chronologically. Features a prominent green "Connect" button (redirects to the MS Teams link) and a "Can't Attend" button.

- "Session History" list showing past classes with status indicators. Includes a download icon button for the session report, which only activates once the Teacher submits it.

- "Quote of the Week" component at the bottom.

- CRITICAL TIME-BASED RATING POPUP: A post-session rating modal must automatically trigger and appear on the student's dashboard exactly 10 minutes BEFORE their scheduled session ends (e.g., if a 1-hour session starts at 5:00 PM, the popup blocks the dashboard at 5:50 PM). This ensures feedback is collected live before the student logs off. This rating updates the teacher's KPI immediately.




2. TEACHER DASHBOARD:

- Personalized agenda displaying ONLY their assigned students and upcoming sessions.

- An intuitive "Active Classes" area with a "Fill Session Report" button. This opens a clean modal to log attendance (Present/Absent/Delayed) and input notes. Teachers have a flexible window of up to 12 hours after the class ends to submit this report. Submitting it completes the status, calculates attendance metrics, and unlocks the report download icon for the student.

- View-only access to the official calendar and core educational materials.





3. ADMIN PANEL (User-Friendly UI with dropdowns and (+) buttons only, no coding concepts):

- Pestaña Courses: Manage levels and units using simple visual forms and (+) adding features.

- Pestaña Students: List, register, or suspend students.

- Pestaña Teachers: View the teacher roster and assign specific students to specific teachers using dropdown selectors 
- Pestaña Sessions: A straightforward scheduling layout. Select Student (dropdown) -> Pick Date/Time -> Paste MS Teams link text box -> Click "Assign" to automatically push it to the student's chronological dashboard.

- Pestaña Material Complementario: Admin uploads supplemental resources. Select Type (dropdown: book, pdf, list, video, image) -> Enables "Upload" file zone -> Automatically categorizes it into the Student's "Resources" page.

- Pestaña KPIs: A high-level analytics dashboard monitoring teachers' performance (punctuality, prompt report submissions, and average star ratings from student popups).




Please generate the base structure, navigation routing, database mock schemas, and the core UI for these pages ensuring a flawless, premium execution.
